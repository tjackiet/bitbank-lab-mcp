# `validateMainPointsNecklineSide` を形成中 triple / double へ配線した実測（issue #261）

`scripts/measure_forming_triple_level_spread_178.ts` の **§6** の出力をそのまま貼ったもの（§3）に、
読み方（§1）と #178 §8 の目視判定との突き合わせ（§2）を足したメモ。

計測ハーネスは PR #260（#178 項目 1 Phase 1）のものをそのまま使い、**#261 の ablation を足しただけ**。
コーパス・ケース数・「延べ / 構造 / 実体」の定義は
[`forming-triple-level-spread-178.md`](./forming-triple-level-spread-178.md) §1 が単一ソース。

## 1. 読み方

- **「配線前」は strip ビルド。** #261 は既に作業ツリーに入っているので、`base` が「配線後」になる。
  「配線前」は `rejectFormingNecklineSide` の本体先頭に `return false;` を差し込んだ複製で再現する
  （アンカーが `detect_triples.ts` / `detect_doubles.ts` にそれぞれちょうど 1 回現れることを挿入前に確認し、
  strip ビルドで新理由コードが 1 件も発火しないことを検算する）。
- **strip ビルドは `main` d86fb2b の実物と主要指標が全一致する。** 別チェックアウトで
  同スクリプトを走らせた出力（配線前）と突き合わせて確認した:

  | 指標 | `main` d86fb2b の実物 | strip ビルド |
  |---|---:|---:|
  | accepted な形成中 triple（延べ / 構造 / 実体） | 7,581 / 111 / 48 | 7,581 / 111 / 48 |
  | うち `spreadRatio > 0.5`（延べ / 実体） | 2,625 / 34 | 2,625 / 34 |
  | 静的判定で誤側（延べ） | 2,698 | 2,698 |
  | accepted な形成中 double（延べ / 構造 / 実体） | 73 / 6 / 4 | 73 / 6 / 4 |

- **実体は延べの OR で生き残る。** 1 実体（同じ 2 つの主構成点）はローリング窓の終端ぶん何十件もの
  延べを持ち、終端が違えば 3 点目（最新足）も違う。**代表窓で誤側でも別の終端では正しい側に来る**ので、
  「代表窓で誤側の実体」がそのまま消えるわけではない。

## 2. #178 §8（目視判定）との突き合わせ

依頼時の見込みは「§8 の 34 実体のうち『ネックライン誤側』24 実体が落ち、残り 10 実体
（呼べない 6 / 保留 1 / 呼べる 3）が残る」だった。**実体単位ではこの見込みは成立しない。**

| §8 の分類 | 実体 | 配線後に `spreadRatio > 0.5` の延べが残るか |
|---|---:|---|
| **(N) ネックライン誤側**（代表窓） | 24 | **16 が落ち、8 が残る**（#1 / #3 / #4 / #7 / #8 / #18 / #21 / #22） |
| (N&#x2032;) 誤側との差が 0.15% 未満 | 3 | 3 とも残る（#2 / #10 / #11） |
| (P) 押しが名目的 | 1 | 残る（#6） |
| (M) 単調な階段 | 2 | 2 とも残る（#14 / #20） |
| 保留 | 1 | 残る（#19） |
| **呼べる** | 3 | **3 とも残る**（#27 / #28 / #30） |

**「残る 10 実体」の側は見込みどおり全件残った。** ずれたのは誤側 24 実体のほうで、うち 8 実体は
**別の終端窓では 3 点目が正しい側に来ており、その窓の `spreadRatio` が 0.5 を超えたまま**なので残る。
代表窓（`spreadRatio` が中央値の延べ）1 件で実体全体の運命を決めた §8 の読みが粗かった、というのが
ずれの理由。**延べ単位では取りこぼしゼロ**（配線前に accepted かつ誤側だった 2,698 延べが、
配線後に 1 件も accepted で残っていない）なので、ゲートの実装が漏れているわけではない。

**#178 項目 1 Phase 2（高さ相対ゲートの形成中への配線）に残る残差は 10 実体ではなく 18 実体。**
内訳は「誤側だが別窓で 0.5 超が残る」8 ＋「もともと誤側ではない」10。
