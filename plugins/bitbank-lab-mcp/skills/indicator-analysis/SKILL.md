# 主要指標分析

`analyze_indicators` の結果だけを使い、勢い・トレンド・ボラティリティの指標を横断して
総合判定と次の転換サインをまとめるスキル。MCP ツール（bitbank-lab-mcp）が使える前提で動く。

## 通貨ペアの決め方

- ユーザーが言った通貨の JPY 建てペアを使う（「ETH」→ `eth_jpy`、「リップル」→ `xrp_jpy`）。
- 指定がなければ `btc_jpy`。
- 対応は JPY 建てのみ。USDT 建てなどを求められたら、JPY 建てしか扱えないことを伝えて
  JPY 建てで進めてよいか確認する。未対応の銘柄はツールがエラーを返すので、そのまま伝える。
- 以下の `<pair>` は決めたペア（`eth_jpy`）、`<PAIR>` はその表示名（`ETH/JPY`）に置き換える。

## ツール

`analyze_indicators(pair=<pair>, type=1day, limit=200)`

## 方針

- 総合判定 → 各指標を横断 → 矛盾は明示 → 次の注目点を具体化、の順に組み立てる。
- content の数値をそのまま使う。指標を自前で計算し直さない。

## 出力

Markdown の見出しで区切る。補足は行頭「└」で書く（前の行の行末にスペース 2 つを入れて改行する）。

# 📊 <PAIR> 日足分析レポート
🔴 / 🟡 / 🟢 の判定 + 現在価格（前日比）

## 📈 勢い指標
### RSI — 数値、█░ ゲージ、初出のみ 1 行説明、直近 n 日の推移 1 行、転換サイン
### MACD — 数値、│ を中央にした簡易バー（ヒストグラムの符号と強さ）、線・シグナル・ヒストグラム、状態・直近の動き・転換サイン

## 📉 トレンド指標
### 移動平均線 — 25 / 75 / 200 と乖離、配置（強気 / 弱気 / 混在）
### 一目均衡表 — 雲の上 / 中 / 下、雲までの距離と厚さ、三役の内訳 3 行、意味 1 行（大型の ASCII テンプレートは不要）

## 📐 ボリンジャーバンド — ±2σ / 中心、現在位置、バンド幅と状態

## 📍 重要な価格帯 — 現在価格を中心にした簡潔な縦リスト（BB ±2σ、雲の上限 / 下限、SMA 25 / 75 / 200）

## ⚖️ 指標の総合判断 — 矛盾するときは短期と中期に分けて説明し、一致するときは結論を書く

## 🎯 次の転換サイン — 反発の条件・下落継続の条件

## 💡 まとめ — 2〜3 行

最後に次の免責事項をそのまま付ける。

---
⚠️ 免責事項：この分析は参考情報であり、解釈には誤差が含まれる場合があります。
板情報は秒単位で変動するため、実際のトレード前には最新状況を再確認してください。
