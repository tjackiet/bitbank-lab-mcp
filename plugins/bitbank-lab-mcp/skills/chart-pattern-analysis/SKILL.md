# チャートパターン分析

`detect_patterns`（中長期のチャートパターン）と `analyze_candle_patterns`（1〜3 本足のローソク足パターン）を
組み合わせ、形成中・完成済み・短期の順に整理してシナリオまでまとめるスキル。
MCP ツール（bitbank-lab-mcp）が使える前提で動く。

## 通貨ペアの決め方

- ユーザーが言った通貨の JPY 建てペアを使う（「ETH」→ `eth_jpy`、「ドージ」→ `doge_jpy`）。
- 指定がなければ `btc_jpy`。
- 対応は JPY 建てのみ。USDT 建てなどを求められたら、JPY 建てしか扱えないことを伝えて
  JPY 建てで進めてよいか確認する。未対応の銘柄はツールがエラーを返すので、そのまま伝える。
- 以下の `<pair>` は決めたペアに置き換える。

## 核心ルール

- 完成から 80 日超のパターン → 無視する
- ターゲット到達済み（達成率 100% 超）→ ⚪低
- 完成から 40 日超 → 最大でも🟡中
- 現在価格がネックライン / ターゲットから 10% 超離れている → ⚪低
- 中間処理の説明は出さない

## ツール

1. `detect_patterns(pair=<pair>, type=1day, limit=180, view=detailed, includeForming=true, includeCompleted=true, requireCurrentInPattern=true, currentRelevanceDays=80)`
   - `limit=180` は意図して据え置いている値（issue #127）。既定の 90 や他の値に変えない。
2. `analyze_candle_patterns(pair=<pair>, timeframe=1day, allow_partial_patterns=false)`
   - ローソク足パターンを検出したら `render_candle_pattern_diagram` で図示する。
     図は自前の SVG やチャートコードで描かず、このツールに任せる。

## 重要度

- 🔴高: 現在価格がネックライン / ターゲットの ±10% 以内で、「⚠️ 余裕が無い軸」の警告行が無い
- 🟡中: ±10% 以内だが、「⚠️ 余裕が無い軸」の警告行がある（検出の境目にある候補）
- ⚪低: それ以外
- 整合度の点数では線を引かない（完成済みパターンの過去の実績では、整合度が高いほど目標に届きやすいという関係は無かった）。

## 出力

## 1. 形成中（切迫性順。なければ「検出なし」）
## 2. 完成済み（完成から 80 日未満、重要度順）
## 3. 短期ローソク足（なければ「検出なし」）
## 4. 総合解釈
## 5. シナリオ（強気 / 弱気 / 中立）
